About This Test Environment

This testing platform replicates 10 key pages from Whistler.com to validate the DMGo recommendation engine. Each page dynamically fetches and displays contextually relevant content tiles based on the page's topic and visitor intent.

  • Pages use Whistler.com's official CSS and design system
  • Recommendations are served via the Python-based DMGo API
  • Tiles are selected using TF-IDF similarity and keyword matching
  • Content is sourced from the DMGo.xlsx tile inventory

Note: This is a test environment for internal use. The recommendation API must be running on localhost:5000 for tiles to load.
